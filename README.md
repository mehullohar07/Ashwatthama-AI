# Ashwatthama AI v0.2 🤖

Ashwatthama is a Python-based personal AI assistant developed from scratch.

## Features

### Applications
- Open Chrome
- Open VS Code
- Open Paint
- Open Notepad
- Open YouTube
- Open Instagram

### Utilities
- Current Date
- Current Time

### System Commands
- Hello
- Help
- Version
- Creator
- Who Are You
  
## Technologies Used

- Python 3

## Project Structure

```text
Ashwatthama-AI/
│
├── main.py
└── commands.py
```

## Run

```bash
python main.py
```
