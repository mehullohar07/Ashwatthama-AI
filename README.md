# Ashwatthama AI v0.1 🤖

Ashwatthama is a Python-based personal AI assistant developed from scratch.

## Features

- Greeting Commands
- Current Date
- Current Time
- Creator Information
- Version Information
- Open Chrome
- Open VS Code
- Open Paint
- Open Notepad
- Open YouTube

## Technologies Used

- Python 3

## Project Structure

```text
Ashwatthama-AI/
│
├── main.py
└── commands.py
```

## Run

```bash
python main.py
```
